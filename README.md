# 🎯 AI Job-Match Copilot

![CI](https://github.com/YOUR_USERNAME/ai-job-match-copilot/actions/workflows/ci.yml/badge.svg)

**Live demo:** https://huggingface.co/spaces/YOUR_USERNAME/ai-job-match-copilot

Upload your resume, paste a job description, and get:

- 📊 **Match score (0–100)**: semantic similarity (sentence-transformer embeddings) combined with skill coverage
- ✅ / ❌ **Skill-gap analysis**: which required skills you have and which are missing
- 📄 **Full resume tailoring**: rewrites the whole resume for the job and shows the new score
- 💬 **Edit with AI**: type instructions like *"add AWS to my skills, I used it in my internship"*; every edit is re-scored against the job, with one-click suggestions and undo
- ✍️ **Tailored resume bullets**: generated by an LLM, without inventing experience
- 🎤 **Likely interview questions**: based on the job and your gaps
- 📥 **Download in your format**: PDF, Word (.docx) or Markdown
- 🔌 **REST API** (FastAPI) with auto-generated docs at `/docs`

## Architecture

```
Resume (PDF) ──► pypdf ──► text ─┐
                                 ├─► Embeddings (all-MiniLM-L6-v2) ─► cosine similarity ─┐
Job description ─────────────────┤                                                       ├─► Match score
                                 └─► Skill extractor ─► matched / missing skills ────────┘
                                                              │
                                                              ▼
                                                LLM (via Groq) ─► tailored resume ⇄ your edit instructions (re-scored each time) ─► PDF / DOCX / MD
```

**Score formula:** `100 × (0.6 × semantic similarity + 0.4 × skill coverage)`

## Tech stack

Python · FastAPI · HTML/CSS/JavaScript (no framework, no build step) · sentence-transformers · OpenAI-compatible LLM API (Groq) · pypdf · pytest · Docker · GitHub Actions · Hugging Face Spaces

## Run locally

```bash
git clone https://github.com/YOUR_USERNAME/ai-job-match-copilot.git
cd ai-job-match-copilot
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # then paste your free Groq key into .env
uvicorn app.api:app --reload
```

Open http://localhost:8000 for the app and http://localhost:8000/docs for the API.

Tests: `pytest`

Docker:
```bash
docker build -t job-match .
docker run -p 7860:7860 --env-file .env job-match
```
